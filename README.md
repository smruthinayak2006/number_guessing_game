# 🎯 Number Guessing Game (Python)

## 📌 Overview
This is a simple command-line Number Guessing Game built using Python.

The program generates a random number between 1 and 100, and the user keeps guessing until the correct number is found. The program provides feedback such as "Higher" or "Lower" to guide the user.

This project was created to practice core programming fundamentals and basic Git workflow.

---

## 🚀 Features
- Random number generation
- User input handling
- Conditional logic (if-elif-else)
- Looping until correct guess
- Basic Git version control

---

## 🛠 Tech Used
- Python 3
- Git
- GitHub

---

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/YOUR-USERNAME/number_guessing_game.git

2. Navigate into the project folder:
   cd number_guessing_game

3. Run the program:
   python main.py
